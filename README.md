## 🎨 Vista Previa y Concepto de Diseño

Diseñada bajo un estilo **moderno, tecnológico, minimalista y elegante**, esta página web actúa como tu tarjeta de presentación digital principal para tu biografía de Instagram y redes profesionales.

- **Paleta Cromática:** Rosa fucsia vibrante (`#ff1493`, `#ff2a8d`), destellos neón, fondo violeta noche (`#0c0517`) y toques en cian eléctrico (`#00f0ff`) que armonizan con el maquillaje y estilo de tu fotografía.
- **Tipografía Inspirada en Canva:**
  - **Títulos y Subtítulos:** Letra cursiva elegante y expresiva (*Dancing Script*).
  - **Textos y Botones:** Tipografía geométrica limpia, moderna y de máxima legibilidad (*Plus Jakarta Sans*, equivalente a *Canva Sans*).
- **Fotografía Integrada:** Tu foto profesional ya está configurada en `assets/avatar.jpg`, enmarcada en un aro giratorio holográfico con enfoque optimizado para retrato.
- **Enfoque Mobile-First:** Optimizada al 100% para los navegadores integrados de smartphones (Instagram In-App Browser, Safari, Chrome).
- **Glassmorphism:** Tarjetas con efecto vidrio esmerilado, bordes redondeados y microinteracciones de luz ambiental.
- **Rendimiento Ultrarrápido:** Carga casi instantánea con HTML5, CSS3 y JavaScript puro.

## 🌐 Publicación Gratuita en GitHub Pages (Paso a Paso)

Publicar tu web para que esté disponible en internet con la dirección `https://proferosarobles19.github.io/Rosa-About-Me/` es 100% gratuito. Sigue estos pasos:

### Paso 1: Crear el Repositorio en GitHub
1. Inicia sesión en [GitHub](https://github.com) con tu cuenta **`proferosarobles19`**.
2. Haz clic en el botón verde **New** (Nuevo Repositorio).
3. Nómbralo exactamente **`Rosa-About-Me`**.
4. Déjalo como **Public** y no agregues README ni .gitignore adicionales (ya los tienes creados).
5. Haz clic en **Create repository**.

### Paso 2: Subir tus Archivos a GitHub

Tienes dos formas muy sencillas de subir los archivos:

#### Método A: Directamente desde el navegador (Sin instalar nada - ¡El más fácil!)
1. Al crear tu nuevo repositorio en GitHub, verás un enlace que dice: **"uploading an existing file"** (o "Add file" > "Upload files").
2. Arrastra y suelta todos los archivos y la carpeta `assets` desde tu computadora hacia la ventana de GitHub:
   - `index.html`
   - `styles.css`
   - `script.js`
   - `README.md`
   - Carpeta `assets/` (con tu foto `avatar.jpg` y el vector `avatar-placeholder.svg`)
3. En la parte inferior, escribe un mensaje como *"Primer lanzamiento"* y haz clic en el botón verde **Commit changes**.

#### Método B: Usando Git en la terminal (si tienes Git instalado)
```bash
git init
git add .
git commit -m "feat: lanzamiento de web personal Rosa Robles Pino"
git branch -M main
git remote add origin https://github.com/proferosarobles19/Rosa-About-Me.git
git push -u origin main
```

### Paso 3: Activar GitHub Pages
1. En tu repositorio de GitHub, haz clic en la pestaña **Settings** (Configuración).
2. En la barra lateral izquierda, busca la sección **Pages**.
3. En **Build and deployment** > **Source**, selecciona:
   - Branch: `main`
   - Folder: `/ (root)`
4. Haz clic en **Save** (Guardar).
5. Espera entre 1 y 2 minutos. GitHub te mostrará un banner verde con tu enlace público oficial:  
   👉 **`https://proferosarobles19.github.io/Rosa-About-Me/`**
